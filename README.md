Kiddy Corner - UAP Pemrograman Web

Deskripsi
  Kiddy Corner adalah aplikasi web berbasis laravel yang berfungsi sebagai website belanja kebutuhan bayi dan mainan anak.
  Aplikasi ini dibuat untuk memenuhi Ujian Akhir Praktikum (UAP) mata kuliah Pemrograman Web.

Aplikasi ini mengimplementasikan:
  - Sistem Autentikasi (login)
  - Manajemen Produk
  - Tampilan UI e-commerce sederhana
  - API untuk pengelolaan data produk
  - Integrasi Database

Fitur utama
  - login Pengguna
  - Menampilkan daftar produk mainan anak
  - Upload dan tampil gambar produk
  - Tambah produk ke keranjang (Cart)
  - Checkout
  - Manajemen Stok produk
  - Rest API

Kelebihan dari Project
- Menggunakan framework Laravel (MVC)
- Struktur kode rapi dan terorganisir
- Sudah menerapkan REST API
- Database terhubung dengan baik
- Upload dan tampil gambar produk
- UI ramah pengguna dengan tema anak-anak
- Menggunakan session untuk cart
- Siap diuji menggunakan Postman

Kekurangan
- Sistem pembayaran masih simulasi (belum real payment gateway)
- Belum ada fitur register user
- Validasi role user masih sederhana
- Belum ada fitur histori transaksi
- Tampilan mobile masih bisa ditingkatkan
- Belum menerapkan middleware authorization secara penuh
